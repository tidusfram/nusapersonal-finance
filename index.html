📱 Cara Install APK di HP Android

Aplikasi ini dapat diinstall langsung di Android dengan 2 cara:

  1. Langsung via Chrome di HP: Buka tautan GitHub Pages di Chrome HP, lalu klik menu titik tiga dan pilih "Tambahkan ke Layar Utama".
  2. Unduh File APK Mandiri: Masukkan URL website ke PWABuilder.com untuk membuat berkas .apk resmi dalam 1 klik.
